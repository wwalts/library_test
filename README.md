# 📚 Library System

![CI/CD Pipeline](https://github.com/wwalts/library_test/actions/workflows/ci-cd.yml/badge.svg)

Система управління бібліотекою: реєстрація читачів, облік книг, видача та повернення.

## Запуск тестів
```bash
pip install -r requirements.txt
python -m pytest tests/ -v
```

## CI/CD
Проєкт використовує GitHub Actions для автоматичного запуску тестів.
